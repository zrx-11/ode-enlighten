# 速查表

## 一阶方程

| 类型 | 标准形 | 解法 | 通解 |
|---|---|---|---|
| 变量分离 | y′=f(x)g(y) | 分离积分 | ∫dy/g(y)=∫f(x)dx+C |
| 齐次型 | y′=φ(y/x) | 令 u=y/x | x du/dx=φ(u)−u |
| 一阶线性 | y′+P(x)y=Q(x) | 常数变易 | y=e^(−∫P)[∫Qe^(∫P)+C] |
| 伯努利 | y′+P y=Q yⁿ | 令 z=y^(1−n) | 化为一阶线性 |
| 恰当 | M dx+N dy=0，M_y=N_x | 求 u | u(x,y)=C |
| 积分因子 x | (M_y−N_x)/N 只含 x | μ=e^(∫…) | 乘后变恰当 |
| 积分因子 y | (N_x−M_y)/M 只含 y | μ=e^(∫…) | 同上 |
| 隐式 | y=f(x,p) | p=y′ 求导 | 参数式 |
| 克莱罗 | y=xp+g(p) | 求导 | 直线族 + 包络奇解 |

## 线性方程

| 场景 | 结论 |
|---|---|
| n 阶齐次解空间 | n 维 |
| 非齐次通解 | 特解 + 齐次通解 |
| 朗斯基 | W(x)=W(x₀)exp(−∫a₁) |
| 常数变易 | Σcᵢ′yᵢ⁽ᵏ⁾=0，最后一式为 f |
| 特征根单实 | e^(rx) |
| 特征根 k 重 | e^(rx), xe^(rx), …, x^(k−1)e^(rx) |
| 复根 α±iβ | e^(αx)cos βx, e^(αx)sin βx |
| 右端 P_m e^(λx) | 特解 xᵏQ_m e^(λx) |
| 右端 e^(αx)(P cos+Q sin) | xᵏe^(αx)(R cos+S sin) |

## 方程组

| 场景 | 结论 |
|---|---|
| 基解矩阵 | Φ′=AΦ，det Φ≠0 |
| 非齐次 | x=Φ[C+∫Φ⁻¹f] |
| det Φ | det Φ(t₀)exp(∫tr A) |
| e^(At) | ΣAᵏtᵏ/k!，满足 Φ(0)=I |
| 对角化 | P diag(e^(λᵢt)) P⁻¹ |
| 若尔当块 | e^(λt)(I+Nt+…+N^(k−1)t^(k−1)/(k−1)!) |
| 拉普拉斯 | X=(sI−A)⁻¹(x₀+F) |

## 稳定性与相图

| 条件 | 类型 |
|---|---|
| tr<0，det>0，Δ>0 | 稳定结点 |
| tr>0，det>0，Δ>0 | 不稳定结点 |
| det<0 | 鞍点 |
| tr<0，det>0，Δ<0 | 稳定焦点 |
| tr>0，det>0，Δ<0 | 不稳定焦点 |
| tr=0，det>0 | 中心 |
| 特征值实部全负 | 渐近稳定 |
| 有正实部 | 不稳定 |
| 实部为零 | 线性化失效 |
