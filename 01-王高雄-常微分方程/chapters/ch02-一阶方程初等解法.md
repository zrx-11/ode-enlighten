# 第 2 章：一阶微分方程的初等解法

- **难度**：★★☆ | **预估学时**：8 小时 | **前置**：第 1 章、不定积分、换元积分、偏导数

## 学习目标
学完本章，你能：
1. 认出并解出四类一阶方程：变量分离、齐次型、一阶线性、恰当方程；
2. 在方程不恰当时，用只依赖 x 或只依赖 y 的积分因子把它救成恰当方程；
3. 解出隐式方程 y=f(x,y′) 与 x=f(y,y′)，会用参数表示写出通解；
4. 判断一个"解"是不是奇解，而不是把它当成通解的特例。

## 一句话核心
一阶方程的初等解法只有一件事：**把方程改写成"某个函数的全微分等于 0"**。分离变量、常数变易、积分因子，都是在凑这个全微分。

## 零基础讲解

### 2.1 变量分离：最原始的一招

形如

<div class="eq">dy/dx = f(x)·g(y)</div>

把含 y 的挪到左边，含 x 的挪到右边：

<div class="eq">dy/g(y) = f(x) dx</div>

两边积分。若 g(y₀)=0，则 y≡y₀ 也是解，这一点必须单独记，否则会丢解。

例：dy/dx = 2xy。分离得 dy/y = 2x dx（y≠0），积分得 ln|y|=x²+c₁，即 y=ce^(x²)。另外 y≡0 也是解。

**为什么能这么干？** 因为 dy/dx 不是分数，但在一阶情形它可以当作微分之比来操作——严格说法是：若 y=φ(x) 是解，则 dφ = f(x)g(φ)dx，两边除以 g(φ) 后积分，链式法则保证左边恰好是 ∫dy/g(y)。

### 2.2 可化为变量分离的两类

**(a) 齐次型** dy/dx = φ(y/x)。令 u=y/x，则 y=ux，dy/dx = u + x·du/dx，方程变成

<div class="eq">x·du/dx = φ(u) − u</div>

这是关于 u 的变量分离方程。解完把 u 换回 y/x。

**(b) 分式线性型**

<div class="eq">dy/dx = (a₁x+b₁y+c₁)/(a₂x+b₂y+c₂)</div>

先看行列式 Δ=a₁b₂−a₂b₁。Δ≠0 时，解线性方程组找出交点 (x₀,y₀)，作平移 X=x−x₀，Y=y−y₀，方程化为齐次型。Δ=0 时，两行成比例，令 u=a₂x+b₂y，直接化为变量分离。

### 2.3 一阶线性方程与常数变易法

标准形

<div class="eq">dy/dx + P(x)·y = Q(x)</div>

**第一步**：先解齐次方程 dy/dx + P(x)y = 0，得 y = c·e^(−∫P dx)。
**第二步（常数变易）**：把常数 c 换成待定函数 c(x)，代回原方程，得到

<div class="eq">c′(x)·e^(−∫P dx) = Q(x)</div>

于是 c(x)=∫Q(x)e^(∫P dx)dx + C，通解为

<div class="eq">y = e^(−∫P dx) [ ∫ Q(x) e^(∫P dx) dx + C ]</div>

这个公式建议直接背，但更该记住它的来源：**齐次解是"骨架"，非齐次的解是在骨架上按 x 逐点调整振幅**。

> 类比：齐次解像一条自由衰减的弹簧振动，非齐次项 Q(x) 像外力，常数变易就是让振幅随时间被外力推着改。类比失效处：Q(x) 与 y 同频率共振时振幅会线性增长，弹簧类比只能给出"越来越大"，给不出精确的 t 倍增长。

### 2.4 恰当方程与积分因子

把方程写成

<div class="eq">M(x,y)dx + N(x,y)dy = 0</div>

若存在 u(x,y) 使 du = M dx + N dy，即

<div class="eq">∂u/∂x = M，∂u/∂y = N</div>

则方程叫**恰当方程**，解就是 u(x,y)=C。判定条件（单连通区域上）：

<div class="eq">∂M/∂y = ∂N/∂x</div>

不满足时找**积分因子** μ，使 μ M dx + μ N dy 恰当，即

<div class="eq">∂(μM)/∂y = ∂(μN)/∂x</div>

两个最常用的特例：
- μ 只依赖 x：需 (∂M/∂y − ∂N/∂x)/N 只是 x 的函数，则 μ=exp(∫(… )dx)。
- μ 只依赖 y：需 (∂N/∂x − ∂M/∂y)/M 只是 y 的函数，则 μ=exp(∫(… )dy)。

求 u 的方法有两条：凑全微分（把 M dx + N dy 拆成几组已知的全微分），或沿折线积分

<div class="eq">u = ∫[x₀,x] M(t,y₀)dt + ∫[y₀,y] N(x,s)ds</div>

### 2.5 隐式方程 y=f(x,y′) 与参数表示

方程里 y′ 解不出来时，把 y′ 当参数 p。

**能解出 y 的类型** y=f(x,p)：对 x 求导得 p = ∂f/∂x + ∂f/∂p·dp/dx，这是关于 p 与 x 的一阶方程，解出 p=p(x,C)，再回代得通解。

**不显含 y 的类型** y=f(x,y′)：同上。
**不显含 x 的类型** x=f(y,y′)：令 p=y′，dx=dy/p，得 1/p = ∂f/∂y + ∂f/∂p·dp/dy，解出 p 后回代。

**克莱罗方程** y = x·p + g(p) 是特例：求导后得 (x+g′(p))·dp/dx = 0，于是要么 p=C 给出一族直线 y=Cx+g(C)，要么 x=−g′(p) 给出**包络**——这条包络是奇解，不属于直线族。

## 类比与实例

**类比**：找积分因子像给方程"配平"。μ 是一个乘数，乘上去不改变解集（只要 μ≠0），却让左边从"两个不相干的偏导"变成"同一个函数的两个偏导"。

**失效边界**：μ 只在 μ≠0 的区域有效。若 μ 在某条曲线上为零，那里可能丢解；另外积分因子一般难以显式求出，教材只处理 μ 只依赖一个变量的情形。

**实例 1**：解 dy/dx = (x+y)/(x−y)。
这是齐次型，令 u=y/x，得 x·du/dx = (1+2u−u²)/(1−u)。分离积分后回代，得到隐式解 x²+y²=C·e^(−2arctan(y/x)) 形式的一族曲线（不同教材整理方式略异，验算时把解代回原方程即可核对）。

**实例 2**：解 (2xy+y²)dx+(x²+2xy)dy=0。
M=2xy+y²，N=x²+2xy。∂M/∂y=2x+2y，∂N/∂x=2x+2y，相等，恰当。取 u=x²y+xy²，解为 x²y+xy²=C。

**实例 3**：解 y=x·p+p²。
求导得 p=p+(x+2p)dp/dx，即 (x+2p)dp/dx=0。p=C 给 y=Cx+C²；另一支 x=−2p 给 y=−p²，即 y=−x²/4，是前者的包络，属于奇解。

## 常见误解

- **别以为"分离变量时除以 g(y) 万事大吉"**——实际上 g(y)=0 的常数解会因此丢掉。y′=y² 的通解是 y=−1/(x+C)，还有 y≡0。
- **别以为"恰当方程的判定条件对所有区域都成立"**——实际上需要区域单连通。挖了洞的区域（如去掉原点的平面）可能 ∂M/∂y=∂N/∂x 却不存在全局的 u。
- **别以为"积分因子唯一"**——实际上同一条方程可以有无穷多个积分因子，教材给的两个公式只是最容易算的两种。
- **别以为"包络也是通解的一员"**——实际上奇解在每一点都与某条通解曲线相切，但它本身不是任何一条通解曲线。

## 自测题（答案）

1. 解 dy/dx = y·tan x。
   （答案：y=C/cos x，另外需注意 cos x=0 的点。解析：分离得 dy/y=tan x dx，积分得 ln|y|=−ln|cos x|+c。）

2. 判断 (y+2xy)dx+(x−2y)dy=0 是否恰当；若否，找一个只依赖 y 的积分因子。
   （答案：∂M/∂y=1+2x，∂N/∂x=1，不恰当。(∂N/∂x−∂M/∂y)/M=(−2x)/(y+2xy)=−2/y，只依赖 y，故 μ=e^(∫−2/y dy)=1/y²。解析：判据中的分母必须是 M 且结果只含 y。）

3. 一阶线性方程 y′+2xy=x 的通解？
   （答案：y=1/2+Ce^(−x²)。解析：∫P dx=x²，y=e^(−x²)[∫x·e^(x²)dx+C]=e^(−x²)[e^(x²)/2+C]。）

4. 克莱罗方程 y=xp+p³ 的奇解是什么？
   （答案：y=−2x^(3/2)/3 的一方与另一支，严格写为参数式 x=−3p²，y=−2p³。消去 p 得 y=±(2/3)·(−x/3)^(3/2)。解析：x+3p²=0 给 p=±√(−x/3)，代回 y=xp+p³。）

5. 为什么说"一阶方程初等解法的本质是凑全微分"？
   （答案：分离变量后 ∫f(x)dx−∫dy/g(y)=C 就是 d(F(x)−G(y))=0；常数变易得到的解可写成 d(y·e^(∫P dx))=Q e^(∫P dx)dx；恰当方程直接就是 du=0。三种方法都在构造同一个 u。）

## 复习锚点
- 分离变量先问一句：除下去的那个因子会不会为零。
- 线性方程的通解公式：y=e^(−∫P)[∫Qe^(∫P)+C]。
- 恰当看 ∂M/∂y=∂N/∂x；不恰当看两个商式哪个只含一个变量。
- 奇解是通解族的包络，不是族里的成员。
