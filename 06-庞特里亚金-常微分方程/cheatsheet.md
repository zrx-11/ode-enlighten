# 速查表

## 常系数齐次

| 根 | 贡献的解 |
|---|---|
| 实单根 λ | e^(λt) |
| 共轭复根 α±iβ | e^(αt)cos βt, e^(αt)sin βt |
| k 重根 λ | e^(λt), t e^(λt), …, t^(k−1)e^(λt) |

## 赫尔维茨判据

| 阶 | 条件 |
|---|---|
| 2 | a>0, b>0 |
| 3 | a>0, c>0, ab>c |
| 4 | 全部顺序主子式 >0 |

## 非齐次

| 右端 | 特解形式 |
|---|---|
| Pₙ(t) | Qₙ(t)（若 0 是根则乘 t^k） |
| e^(αt)Pₙ(t) | e^(αt)Qₙ(t)（若 α 是根则乘 t^k） |
| 正弦/余弦 | 复振幅法：(A−iωI)u=−b |

## 变系数

| 场景 | 结论 |
|---|---|
| 基解矩阵 | Φ̇=AΦ，det≠0 |
| 非齐次 | x=Φ[C+∫Φ⁻¹b] |
| 刘维尔 | det Φ=exp(∫tr A) |
| 周期系统 | Φ(t+T)=Φ(t)M |

## 存在性

| 结论 | 内容 |
|---|---|
| 最大区间出口 | 到边界 / 爆破 / 到无穷 |
| 首次积分数 | n−1 |
| 局部 vs 整体 | 整体要多假设不逸出 |

## 稳定性

| 概念 | 判据 |
|---|---|
| 线性化 | 实部全负渐近稳定 |
| 第二方法 | V 正定、V̇ 负定 |
| 极限环存在 | 平面 + 捕获域 + 无平衡点 |
| 极限环稳定 | 庞加莱映射导数 <1 |
