# 模式与框架库

## 框架：证明存在性的两条路线
- **构造型**：积分方程 → 迭代 → 阶乘估计 → 一致收敛。需要李普希茨。
- **紧性型**：欧拉折线 → 等度连续 → Ascoli-Arzelà → 取子列。只需连续。

做题时先问"要不要唯一"：要唯一必须验证李普希茨，只证存在可走紧性路线。

## 框架：从"唯一性失效"看奇解
1. 通解是否漏解？
2. 漏掉的解是否与族相切？
3. 该点李普希茨是否失效？

三条串起来，奇解就从"技巧性概念"变成"唯一性定理的例外"。

## 决策规则
- 一阶方程：先凑全微分；不成找 μ；μ 只依赖一个变量才可算。
- 线性方程组：齐次找基解矩阵，非齐次用常数变易。
- 边值问题：先解齐次，用二择一判可解性。
- 稳定性：先线性化，非双曲再找 V。

## 反模式
- **用判别式直接下结论**：必须回代检验。
- **把"局部解"当"整体解"**：必须延拓。
- **对非线性系统硬套常数变易**：只对线性有效。
- **把"稳定"当"渐近稳定"**：中心型稳定但不渐近。
