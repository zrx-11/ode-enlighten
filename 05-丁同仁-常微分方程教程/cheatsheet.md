# 速查表

## 初等解法

| 类型 | 处理 |
|---|---|
| 恰当 P dx+Q dy=0 | P_y=Q_x，求 u |
| 不恰当 | μ(x) 或 μ(y) |
| 分离变量 | μ=1/g(y) |
| 平移型 y′=f(ax+by+c) | u=ax+by+c |
| 齐次型 y′=φ(y/x) | u=y/x |
| 隐式 y=f(x,p) | 对 x 求导 |

## 存在唯一性

| 定理 | 条件 | 结论 |
|---|---|---|
| 皮卡 | 连续 + 李普希茨 | 唯一 |
| 皮亚诺 | 连续 | 存在 |
| 格朗沃尔 | D≤A+∫BD | D≤A e^(B|x−x₀|) |
| 变分方程 | f 对 y 可微 | Φ′=f_yΦ，Φ(x₀)=I |

## 线性

| 场景 | 结论 |
|---|---|
| 齐次方程组 | 解空间 m 维 |
| 非齐次 | y=Φ[C+∫Φ⁻¹f] |
| 常系数 | e^(At) |
| 重特征值 | e^(λt)(I+Nt+…) |

## 解析

| 点型 | 方法 |
|---|---|
| 常点 | 幂级数 |
| 正则奇点 | 弗罗贝尼乌斯，指标方程 r(r−1)+p₀r+q₀=0 |
| 非正则 | 一般无级数解 |

## 定性

| 条件 | 类型 |
|---|---|
| q<0 | 鞍点 |
| q>0, Δ>0, p<0 | 稳定结点 |
| q>0, Δ<0, p<0 | 稳定焦点 |
| q>0, p=0 | 中心 |

## 边值

| 结论 | 内容 |
|---|---|
| 二择一 | 齐次零解 ⇔ 非齐次唯一可解 |
| 正交性 | ∫ρ yₘyₙ=0 |

## PDE

| 类型 | 通解 |
|---|---|
| a u_x+b u_y=0 | u=F(Φ) |
| 拟线性 | 特征方程组 + 初始曲线 |
| 非特征条件 | a dy₀/dτ−b dx₀/dτ≠0 |
