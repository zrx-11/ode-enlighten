# 第 1 章：微分方程的基本概念

- **难度**：★☆☆ | **预估学时**：2 小时 | **前置**：微积分
- **对应原书**：第一章

## 学习目标
学完本章，你能：
1. 说清"常"与"偏"的分界在哪；
2. 判断阶数与线性性，并说明为什么 y′=y(y−1) 不是线性方程；
3. 解释通解为什么不等于"全部解"，并给出一个具体反例；
4. 由一族含 n 个任意常数的曲线反求它所满足的微分方程。

## 一句话核心
常微分方程研究的是"一元函数的局部变化规律"，通解是局部规律的积分产物，它天生可能漏掉某些解。

## 零基础讲解

### 1.1 "常"字的含义

未知函数是一元函数，方程里只出现常导数；未知函数是多元函数、出现偏导数，就是偏微分方程。平面 Laplace 方程 u_xx+u_yy=0 有两个自变量，所以它不是常微分方程。

教材在这里特意点出：**定义里的"阶"指的是实际出现的最高阶导数**，而不是方程里写了几个导数符号。y′=y 是一阶，y″+y′=y 是二阶。

### 1.2 解、通解与"漏解"

定义很直白：代入后成为恒等式的函数就是解。麻烦在通解。

教材的注 1.3 举了一个必须记住的例子：方程

<div class="eq">dy/dx = y²</div>

的通解是 y=−1/(x−c)（x>c 那一支），但 y≡0 也是解，且不属于这个函数族。原因很简单：分离变量时把 y² 除下去了，y=0 被排除在讨论之外。

所以"n 阶方程的通解含 n 个任意常数"这句话只描述解族的规模，不承诺覆盖所有解。这是后续"奇解"概念的伏笔。

### 1.3 由曲线族反求方程

给一族曲线 y=φ(x; c₁,…,cₙ)，要求消去常数得到微分方程。做法是：连续求导 n 次，得到 n+1 个方程（含原式），从中消去 c₁,…,cₙ。

例：y=c₁x+c₂x²。求导得 y′=c₁+2c₂x，再求导得 y″=2c₂。由第二式 c₂=y″/2，代回第一式得 c₁=y′−xy″。再代入原式：

<div class="eq">y = (y′−x·y″)x + (y″/2)x² = xy′ − x²y″/2</div>

整理得 x²y″−2xy′+2y=0。这正是欧拉方程的一个特例。

### 1.4 几何意义：线素场

对 y′=f(x,y)，在每点画一段斜率为 f(x,y) 的短线，得到**线素场**。使 f 无定义或为不定式的点叫**奇异点**，它们往往是积分曲线族的中心或汇集点。

例：y′=y/x。等斜线 f(x,y)=k 是直线 y=kx，而这条直线本身的斜率也是 k，所以它与线素场完全吻合，积分曲线就是从原点出发的射线族。原点就是奇异点。

> 类比：线素场像一张"风向图"，积分曲线是一片叶子的漂移轨迹。
> 失效边界：奇异点处风向没有定义，叶子在那儿可以停住不动（常数解经过奇异点时行为要单独分析）。

看图说明：箭头方向说明"曲线族 → 方程"是求导消参，"方程 → 曲线族"是积分。后者会丢信息（丢的就是那些被除掉的因子对应的解）。

## 类比与实例

**类比**：求导是"降信息"的操作，积分是"补信息"的操作，但补回来的信息里，常数是猜的。所以从方程回到解，必然会丢掉那些"不含任意常数"的孤立解。

**实例**：验证 y=±√(c−x²)（|x|<√c）是 y′=−x/y 的解。求导：y′=−x/y 直接成立（对 y 求导得 −x/y）。但把 c=0 代入得 y=0，而 y=0 不满足原方程（分母为零），说明这个"解"是在开区间上成立的。

## 常见误解

- **别以为"通解就是所有解"**——实际上 y′=y² 的 y≡0 不在通解族里。
- **别以为"方程里出现几个导数符号就是几阶"**——实际上看最高阶。
- **别以为"曲线族反求方程唯一"**——实际上消参方式不同可能得到等价但形式不同的方程。

## 自测题（答案）

1. 判断 y″+sin y=0 的阶数与线性性。
   （答案：二阶，非线性。解析：sin y 关于 y 不是一次式。）

2. 求曲线族 y=c₁eˣ+c₂e^(2x) 满足的微分方程。
   （答案：y″−3y′+2y=0。解析：特征根 1、2 对应特征方程 (r−1)(r−2)=0，展开即得。）

3. 为什么 y≡0 是 y′=y² 的解却不在通解族里？
   （答案：分离变量时除以 y² 把它排除了。解析：这是"除零丢解"的典型例子。）

4. 线素场的奇异点有什么特点？
   （答案：f 在该点无定义或为不定式，方向不确定。解析：常是积分曲线族的中心或汇聚点。）

## 复习锚点
- "常"指一元函数；阶看最高阶导数。
- 通解含 n 个常数，但不保证覆盖全部解。
- 曲线族求方程 = 求导 n 次再消参。
