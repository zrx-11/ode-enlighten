# 综合检验建议

## 跨书整合题

### 题 1：同一个初值问题，三种讲法
- 涉及：01 第 3 章、04 第 3 章、05 第 3 章、07 第 6 章
- 任务：取 y′=√|y|，y(0)=0。分别用皮卡、皮亚诺、压缩映射三种框架说明"为什么存在""为什么不唯一"，并指出三者假设的差别。
- 评分要点：
  1. 皮卡：指出李普希茨失效，故不能断言唯一；
  2. 皮亚诺：f 连续，故至少一个解；
  3. 压缩映射：指出 q<1 不成立，迭代不收敛；
  4. 能构造至少两个具体解（y≡0 与延迟出发解）。

### 题 2：稳定性的四种判据对照
- 涉及：01 第 6 章、05 第 8 章、06 第 2/5 章、07 第 4 章
- 任务：对同一个线性系统 ẋ=Ax（自选一个 3×3 矩阵），分别用特征值、赫尔维茨判据、李雅普诺夫方程、相平面分类四种方法判断稳定性，比较计算量与结论强度。
- 评分要点：
  1. 四种方法结论一致；
  2. 说清赫尔维茨判据只用系数，不解方程；
  3. 说清李雅普诺夫方程给出 P，可用于构造 V；
  4. 指出非双曲时四种方法的失效情况。

### 题 3：从相图到工程判断
- 涉及：06 第 5 章、07 第 1/3 章
- 任务：以范德波尔方程建模一个电子管振荡器，说明平衡点为什么失稳、极限环为什么稳定、振幅由什么决定。
- 评分要点：
  1. 线性化给出原点不稳定；
  2. 大振幅处能量耗散，轨线被拉回；
  3. 极限环唯一且稳定；
  4. 能画出相图并标出方向。

### 题 4：边值问题的可解性
- 涉及：04 第 7 章、05 第 9 章、03 第 8 章
- 任务：对 y″+λy=f，y(0)=y(1)=0，讨论 λ 取何值时无解、唯一解、无穷多解，并用格林函数或特征函数展开写出解。
- 评分要点：
  1. λ<0 与 λ>0 非特征值：唯一解；
  2. λ=n²π²：需 ∫f sin(nπx)=0，否则无解；
  3. 写出展开式系数；
  4. 指出格林函数在共振时不存在。

### 题 5：一阶 PDE 的两种视角
- 涉及：01 第 7 章、05 第 10/11 章、07 第 2 章
- 任务：解 u_x+u_y=u，u(x,0)=x。分别用首次积分法、特征线法、几何（流箱）三种说法解释解 (x−y)e^y 的来源。
- 评分要点：
  1. 特征方程组；
  2. 首次积分与任意函数；
  3. 非特征条件验证；
  4. 回代检验。

## 进阶路线

1. **偏理论**：05 全书 → 阿诺尔德第 7 章 → 常微分方程与动力系统（Hartman、Coddington-Levinson）→ 分支理论与 KAM。
2. **偏工程**：06 第 2、5 章 → 稳定多项式与劳斯-赫尔维茨 → 控制理论基础（状态空间、李雅普诺夫稳定性、LQR）。
3. **偏计算**：03 第 8 章 → 数值方法（Runge-Kutta、刚性方程、辛几何算法）→ 用 Python/MATLAB 做相图与分岔图。
4. **偏几何**：07 全书 → 微分流形与向量场 → 辛几何与哈密顿力学。
