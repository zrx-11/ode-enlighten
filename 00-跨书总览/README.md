# 跨书总览：常微分方程学习路线

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 王高雄《常微分方程》第四版（01） | 国内最通用的本科教材，主线清楚：解法—存在唯一—线性—稳定性—PDE—边值 | 能独立做出课后基础题，说清八章各解决什么问题 |
| 2 | 朱思铭《学习辅导与习题解答》（02） | 与 01 逐章对应，把定理翻译成考场动作 | 看到题目三分钟内能定解法路线 |
| 3 | 《第四版习题详解》（03） | 与 01、02 同一体系，题量最大，用来巩固 | 每章能独立完成 80% 习题 |
| 4 | 柳彬《常微分方程》（04） | 同一层次但更重理论边界：积分因子主线、Peano 定理、变分方程、Sturm 比较 | 能说清每个定理的条件为什么不能删 |
| 5 | 丁同仁、李承治《常微分方程教程》（05） | 理论最完整的中文教材：奇解单列、解析理论、定性理论、首次积分 | 能独立完成证明题，包括皮卡与皮亚诺两套 |
| 6 | 庞特里亚金《常微分方程》（06） | 工程视角：稳定多项式、复振幅法、电路、调速器、振荡器 | 能把数学结论翻译成工程判断（会不会振、会不会炸） |
| 7 | 阿诺尔德《常微分方程》（07） | 几何视角：相流、向量场、流形、奇点指数 | 能用相空间语言描述问题，理解"为什么这样选相空间" |

## 各书定位（一句话）
- 《01 王高雄》：标准教科书，先把"会算"打牢。
- 《02 朱思铭》：解题手册，把知识变成动作。
- 《03 习题详解》：题海，练熟练度。
- 《04 柳彬》：理论边界的第一次提醒——条件为什么必须。
- 《05 丁同仁》：理论完整版，证明链齐全。
- 《06 庞特里亚金》：数学落到工程，稳定性有了物理意义。
- 《07 阿诺尔德》：几何重构，把方程变成流。

## 学习节奏建议
- 第 1–3 周：01 的前四章 + 02 对应章节，配合 03 刷题。目标是"会算"。
- 第 4–5 周：01 的后四章，同时读 04 的对应章节，比较两书对同一概念的处理。
- 第 6–8 周：05 的第 3、5、6、8、9 章，补全证明链。这周开始以证明为主，计算题为辅。
- 第 9–10 周：06 的第 2、5 章，把稳定性接到工程实例上。
- 第 11–12 周：07 的第 1、3、7 章，重建几何直觉。
- 每周留半天做交叉复习：用《跨书概念映射表》对照同一概念在各书的讲法。

## 总入口
打开 `index.html` 总学习手册，按顺序推进；每本书的进度独立保存。
