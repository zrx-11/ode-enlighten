# 第 8 章 数学软件与数值实验

- **难度**：★★☆ | **预估学时**：4 小时 | **前置**：第 1–7 章
- **对应原书**：第十章（数学软件）

## 学习目标
学完本章，你能：
1. 用 SymPy/Mathematica 符号求解一阶与线性方程；
2. 用 MATLAB/SCILAB 做数值积分并画相图；
3. 说明符号解与数值解各自的边界；
4. 用软件验证手算结果（这是最实用的用法）。

## 一句话核心
软件不是用来"代替手算"的，而是用来**验证手算和画图**的。符号解告诉你公式对不对，数值解告诉你轨线长什么样。

## 零基础讲解

### 8.1 符号求解

SymPy：

```python
from sympy import Function, dsolve, Eq, symbols
x = symbols('x'); y = Function('y')
dsolve(Eq(y(x).diff(x), x + y(x)), y(x))
```

输出含 eˣ 与积分项，可与手算对照。

Mathematica：DSolve[{y'[x]==x+y[x], y[0]==0}, y[x], x]。
Maple：dsolve({diff(y(x),x)=x+y(x), y(0)=0})。

### 8.2 数值求解

MATLAB：ode45(@(t,y) t+y, [0 5], 0)。
SCILAB：ode(0, t, y0, f)。

**注意**：数值解只给一个初值对应的一条轨线，不能代替相图分析。

### 8.3 画相图

用 quiver（MATLAB）或 matplotlib 的 streamplot 画向量场。这是理解定性理论最直观的方式。

### 8.4 验证流程

1. 手算得解。
2. 软件符号求解，比对形式。
3. 数值积分，比对数值。
4. 画图，检查定性行为（是否闭合、是否收敛）。

四步走完，答案基本可靠。

## 类比与实例

**类比**：软件像"计算器 + 望远镜"。计算器验算，望远镜看全局形状。两者都不能代替你理解题目。

**失效边界**：符号求解在无初等解时会返回隐式或未求值形式；数值求解在刚性方程上会失真。

**实例**：y′=y²，y(0)=1 的手算解是 1/(1−t)，在 t=1 爆破。数值积分到 t=1 附近会出现溢出——这正好验证了"最大区间有限"的结论。

## 常见误解

- **别以为"软件给的解一定对"**——符号解可能漏分支。
- **别以为"数值解能看出稳定性"**——单条轨线看不出全局。
- **别以为"软件能替代证明"**——它只给计算结果。

## 自测题（答案）

1. SymPy 求解析解的函数？
   （答案：dsolve。解析：符号求解入口。）

2. 数值解能代替相图吗？
   （答案：不能。解析：只给单条轨线。）

3. 刚性方程数值积分为何失真？
   （答案：显式方法需要极小步长，否则不稳定。解析：刚性导致稳定域限制。）

4. 软件验证的四步？
   （答案：手算、符号、数值、画图。解析：四重校验。）

## 复习锚点
- 符号解验公式，数值解验数值，画图验定性。
- 软件不能替代证明。
- 四重校验流程。
