# 速查表

## 一阶

| 类型 | 处理 |
|---|---|
| 可分离 | 分离后积分，注意 g(y₀)=0 |
| 恰当 | P_y=Q_x，求 u |
| 线性 y′+Py=Q | μ=e^(∫P) |
| 伯努利 | z=y^(1−n) |
| 齐次 y′=φ(y/x) | u=y/x |
| 平移 y′=f(ax+by+c) | u=ax+by+c |

## 存在唯一

| 要证 | 用什么 |
|---|---|
| 存在 | 皮亚诺（连续） |
| 唯一 | 皮卡（连续 + 李普希茨） |
| h | min(a, b/M) |

## 高阶线性

| 右端 | 特解 |
|---|---|
| Pₙ(x) | Qₙ(x)x^k（0 是 k 重根） |
| e^(αx)Pₙ | e^(αx)Qₙ x^k（α 是 k 重根） |
| 正弦余弦 | 转复指数处理 |

## 方程组

| 情形 | 方法 |
|---|---|
| 单特征值 | [vᵢe^(λᵢt)] |
| 复特征值 | 实部虚部 |
| 重特征值 | 广义特征向量 |
| 非齐次 | 常数变易 |

## 稳定性

| 步骤 | 内容 |
|---|---|
| 1 | 解 f=0 |
| 2 | 算 J |
| 3 | 算特征值 |
| 4 | 判符号 |
| 5 | 临界时解 AᵀP+PA=−Q |

## PDE / 边值

| 类型 | 结论 |
|---|---|
| a u_x+b u_y=0 | u=F(Φ) |
| 拟线性 | 特征方程组 |
