# 模式与框架库

## 框架：判断顺序（本章最值钱的东西）
1. 可分离？
2. 恰当（P_y=Q_x）？
3. 单变量积分因子？
4. 换元（齐次、平移、伯努利）？
5. 隐式/参数法？

走完再动手，别边算边试。

## 框架：线性方程两段式
- 齐次：特征根 → 基础解系。
- 非齐次：识别右端 → 待定系数（注意共振）或常数变易。

## 决策规则
- 只证存在：用皮亚诺，不必验李普希茨。
- 要证唯一：必须验李普希茨并给 h。
- 判稳：先线性化，非双曲再解李雅普诺夫方程。
- 边值：先解齐次，用二择一。

## 反模式
- 通解写完就交（漏奇解、漏常数解）。
- 共振忘了乘 x^k。
- 稳定性只分析一个平衡点。
- 引用定理不验条件。
