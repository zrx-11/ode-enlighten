# 《常微分方程》（阿诺尔德）点化学习系统

## 这本书在讲什么
阿诺尔德这本书的根本立场是几何的：常微分方程不是"求解公式的技术"，而是"相空间上的流"。他从确定过程讲到相流、向量场、常点附近的拉直、首次积分、线性算子指数、稳定性、周期系数，最后把一切都搬到流形上，用奇点指数收尾。

## 全书心智模型

```mermaid
flowchart TD
    A[确定 有限维 可微] --> B[相空间与相流]
    B --> C[相速度场]
    C --> D[常点: 流箱拉直]
    C --> E[奇点: 需专门分析]
    E --> F[线性化 e^(At)]
    F --> G[稳定性 谱]
    C --> H[首次积分]
    H --> I[保守系统 等能线]
    B --> J[流形 切丛]
    J --> K[奇点指数]
```
