# 第 3 章：线性系统与算子指数

- **难度**：★★★ | **预估学时**：10 小时 | **前置**：第 2 章、线性代数
- **对应原书**：第二章中段（§13–§22）

## 学习目标
学完本章，你能：
1. 用算子指数 e^(At) 表示线性系统的相流；
2. 说明指数的三条性质（群性质、可逆性、行列式）；
3. 处理互不相同的实特征值、复特征值与重特征值三种情形；
4. 按特征值分类线性系统的奇点，并区分"代数分类"与"拓扑分类"。

## 一句话核心
线性系统的相流就是一个线性算子：**φᵗ=e^(At)**。所有关于线性系统的几何结论，都是这个算子的谱性质。

## 零基础讲解

### 3.1 算子指数

<div class="eq">e^(At) = I + At + (At)²/2! + …</div>

性质：
1. **群性质**：e^(A(s+t))=e^(As)e^(At)。
2. **可逆**：逆是 e^(−At)。
3. **行列式**：det e^(At)=e^(t·tr A)。

第三条是刘维尔公式的算子版本：相流的"体积伸缩率"由迹决定。迹为零 ⇒ 保面积（哈密顿系统的特征）。

### 3.2 三种特征值情形

- **互不相同的实特征值**：e^(At) 在特征向量基下是对角的，轨线沿特征方向进出。
- **复特征值**：实化后得到旋转 + 伸缩，轨线是螺旋。
- **重特征值**：若尔当块给出"旋转 + 平移"的复合，轨线可能贴着特征方向走。

### 3.3 奇点的代数分类

按特征值：结点（实、同号）、鞍点（实、异号）、焦点（复、有实部）、中心（纯虚）。

### 3.4 奇点的拓扑分类

阿诺尔德在这里做了一件其它教材常忽略的事：**代数分类不等于拓扑分类**。例如"稳定结点"在拓扑上都是一样的（都是把邻域压向一点），但"焦点"与"结点"在拓扑上不同（一个绕、一个不绕）。

更精细的是：**结点与焦点在拓扑上可以互相转化**（通过同宿轨的分界），所以拓扑分类比代数分类粗，但更本质。

## 类比与实例

**类比**：e^(At) 像"一台机器"，输入初始状态，输出 t 时刻状态。特征值决定这台机器是"压扁"、"拉伸"还是"旋转"。

**失效边界**：非线性系统的相流不是算子指数，只能局部近似。

**实例**：A=[[0,−1],[1,0]]。e^(At)=[[cos t,−sin t],[sin t,cos t]]，det=1（保面积），轨线是圆。对应中心。

**实例 2**：A=[[−1,1],[0,−1]]。e^(At)=e^(−t)[[1,t],[0,1]]。轨线螺旋趋近原点，但因为有 t 因子，趋近方向贴着一条直线——这是"退化结点"。

## 常见误解

- **别以为"代数分类就是全部"**——实际上拓扑分类更粗但更本质。
- **别以为"det e^(At) 恒为 1"**——实际上等于 e^(t tr A)。
- **别以为"重根一定是结点"**——实际上可能是退化结点或焦点型。

## 自测题（答案）

1. det e^(At) 等于什么？
   （答案：e^(t tr A)。解析：刘维尔公式的算子版。）

2. 迹为零意味着什么几何性质？
   （答案：相流保面积。解析：det=1。）

3. 结点与焦点在拓扑上是否相同？
   （答案：不同（一个不绕、一个绕），但可通过同宿分界互相转化。解析：见 §22。）

4. 复特征值对应的轨线形状？
   （答案：螺旋。解析：旋转加伸缩。）

## 复习锚点
- 线性相流 = e^(At)。
- det=e^(t tr A)，迹零保面积。
- 代数分类与拓扑分类是两回事。
